Spacing & Layout

Spacing Scale

4px — micro gap (icon spacing, badge inner padding)
8px — xs (topbar padding, small gaps)
12px — sm (button gap, tight spacing)
18px — md (metric padding, grid gap small)
24px — lg (testi card padding, footer padding)
32px — xl (container padding, form card padding)
40px — 2xl (hero metrics margin-top)
52px — 3xl (mobile section padding)
64px — 4xl (about grid gap)
88px — 5xl (desktop section padding: padding: 88px 0)

Layout Rules

Container: max-width: 1200px · margin: 0 auto · padding: 0 32px (mobile: 0 18px)
Radius (--r): 4px — buttons, badges, form inputs
Radius (--rlg): 8px — cards, panels, dropdowns, images
Section padding: 88px top/bottom desktop · 52px mobile
Hero: min-height 86vh · 2-column grid (1fr 1fr) · left col padding 56px right
Grid gap (cards): 18–22px standard · 12–14px compact
Easing: cubic-bezier(.25,.46,.45,.94) — used on all card/hover transitions
Transition speed: 0.2s standard · 0.3s cards/complex · 0.65s reveal animations

Breakpoints

≤ 1100px: Hide main nav (show hamburger) · 2-col industries/related · 1-col why-layout · 4→2 process steps · 2-col footer
≤ 880px: 1-col hero (hide hero image) · 1-col about/form · 1-col features/values/testimonials
≤ 768px: 18px container padding · 2-col offices · 1-col products/fabrics · section 52px padding
≤ 480px: 1-col industries/offices/related · stack hero actions vertically
